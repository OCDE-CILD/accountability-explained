# Accountability Explained - Site Starter

This starter contains the first working pages for the Accountability Explained platform.

## Included
- Discovery Portal (Table 9 student groups in order)
- Foster Youth 3-point entry page
- Understanding Foster Youth - Page 1
- Narration script included on the Understanding page
- Shared stylesheet

## How to use with GitHub Desktop
1. Download and unzip this package.
2. Open or clone the `accountability-explained` GitHub repository with GitHub Desktop.
3. Copy these files into the repository folder.
4. Commit and push to GitHub.

## File structure
- `index.html` = Discovery Portal
- `domains/foster-youth/index.html` = Foster Youth 3-point entry
- `domains/foster-youth/understanding/index.html` = Understanding Foster Youth - Page 1
- `assets/styles.css` = Site styles
- `docs/sprint-1-content-foundation.md` = Reference copy of the content foundation
