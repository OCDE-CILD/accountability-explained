# Domain Blueprint v1

## Purpose
Defines the standard structure for every Accountability Explained domain.

## Domain Structure

```text
domain/
├── index.html
├── 01-understanding/
│   └── index.html
├── 02-guided-learning/
│   └── index.html
└── 03-accountability-connections/
    └── index.html
```

## Page Purposes

### Domain Landing Page
- Orient the learner
- Introduce the student group
- Provide navigation into the learning experience

### Understanding
- Build foundational knowledge
- Define concepts and context
- Establish shared understanding

### Guided Learning
- Provide a structured learning pathway
- Present content in a logical sequence
- Reinforce key ideas

### Accountability Connections
- Connect the domain to accountability systems
- Show relationships to indicators and measures
- Link to related domains and resources

## Design Standards
- Shared CSS and JavaScript assets
- Domain-specific colors
- Consistent navigation
- Consistent page layouts
