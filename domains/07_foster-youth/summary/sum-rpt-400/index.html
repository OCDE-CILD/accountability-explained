Dashboard Indicator Considerations

Student Population

Indicators include different student populations.

Reporting Period

Some use a single year, others use multiple years.

Student Cohort

Some indicators follow students over several years.

Inclusion Criteria

Indicators are calculated in different ways.

★
KEY TAKEAWAY

Even within the California School Dashboard, indicators are not always calculated using the same group of students. Each accountability measure applies its own denominator, reporting period, cohort definition, and inclusion criteria based on what that indicator is designed to measure.

This means two Dashboard indicators can report different Foster Youth counts and still be completely accurate. Understanding the calculation rules behind each indicator is essential before comparing results or drawing conclusions about student performance.
